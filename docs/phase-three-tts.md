# 第三阶段：导游语音播报

更新时间：2026-07-16

## 阶段目标

在第二阶段“灵山胜境知识库 + Dify RAG”文字问答基础上，为导游回答增加浏览器端语音播报能力。

当前实现使用浏览器原生 Web Speech API，不需要额外购买 TTS 服务，也不需要把文本发送到新的第三方语音接口。

## 已实现功能

- 导游回答气泡支持播放、暂停、继续和重播。
- 顶部提供“自动播报”开关。
- 自动播报偏好保存在浏览器本地，下次打开页面仍然生效。
- 游客发起新问题时，会自动停止上一条正在播放的导游语音。
- 浏览器不支持 Web Speech API 时，语音按钮自动隐藏或禁用，不影响文字问答。

## 使用方式

启动后端：

```powershell
cd /d D:\ai-scenic-guide\services\api-server
.venv\Scripts\python.exe -m uvicorn app.main:app --host 127.0.0.1 --port 8000
```

启动前端：

```powershell
cd /d D:\ai-scenic-guide\apps\visitor-web
npm.cmd run dev
```

打开：

```text
http://localhost:5173/
```

在导游回答下方点击“播放”即可朗读回答；开启“自动播报”后，每次导游回答会自动朗读。

- 半日游路线怎么走？
- 带老人去灵山胜境怎么玩比较合适？

## 注意事项

浏览器原生语音的音色取决于操作系统和浏览器内置语音包。正式部署到景区设备前，应在目标设备上测试中文语音、扬声器音量和全屏浏览器权限。

如果后续需要更自然的声音，可将 Web Speech API 替换为云端 TTS 服务，例如讯飞、阿里云、火山引擎或 Edge TTS。前端语音控件可复用，只需要替换音频生成和播放方式。
