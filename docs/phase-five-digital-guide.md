# 第五阶段：数字人导游形象与展示模式

更新时间：2026-07-16

## 阶段目标

在文字问答、Dify RAG、语音播报和语音输入基础上，增加可在景区设备上展示的数字人导游形象。

本阶段采用轻量前端数字人组件，不引入未知许可证的 GitHub 项目，避免依赖 GPU、复杂后端流媒体或不可控授权。后续如果确定使用 Live2D、Three.js、Unity 或真实数字人项目，可将该组件替换为更高阶实现。

## 已实现功能

- 新增数字人导游形象组件。
- 支持待机、聆听、检索和讲解四种状态。
- 语音播报时显示嘴型和声波动画。
- 语音输入时显示“正在聆听”状态。
- Dify 请求等待期间显示“正在检索”状态。
- 新增“展示模式”按钮，适配景区触摸屏和大屏演示。

## 使用方式

启动后端：

```powershell
cd /d D:\ai-scenic-guide\services\api-server
.venv\Scripts\python.exe -m uvicorn app.main:app --host 127.0.0.1 --port 8000
```

启动前端：

```powershell
cd /d D:\ai-scenic-guide\apps\visitor-web
npm.cmd run dev
```

打开：

```text
http://localhost:5173/
```

点击页面右上角“展示模式”可切换景区终端展示布局。开启自动播报后，导游回答时数字人会进入讲解状态。

## 验收场景

1. 打开页面后可看到黄山 AI 数字人导游形象。
2. 点击麦克风提问时，数字人进入“正在聆听”状态。
3. 发送问题并等待 Dify 返回时，数字人进入“正在检索”状态。
4. 导游回答播放语音时，数字人进入“正在讲解”状态。
5. 点击“展示模式”后页面更适合大屏或触摸屏演示。
