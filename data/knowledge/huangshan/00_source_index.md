# 黄山风景区知识库索引

更新时间：2026-07-16
适用项目：AI景区数字人导游 / Dify RAG 知识库
建议知识库名称：黄山风景区导游知识库

## 使用原则

1. 本知识库用于游客问答、路线推荐、服务咨询和文化讲解。
2. 开放时间、票价、索道运营时间、优惠政策、临时交通管制和极端天气开放状态具有强时效性，回答时必须提示游客以黄山风景区官方公告、黄山旅游官方平台、现场游客中心和工作人员说明为准。
3. 对无法确认的信息，不要编造。应回答“当前知识库未收录可靠信息”，并建议拨打旅游咨询电话 0559-2590999 或查看官方平台。
4. 黄山山地游览体力消耗大，涉及老人、儿童、雨雪天气、夜间、未开放区域等问题时优先给安全提醒。

## 文件说明

- `01_overview.md`：景区概况、地理、荣誉、五绝、气候和生态。
- `02_culture_history.md`：得名由来、黄帝文化、徐霞客评价、黄山文化。
- `03_routes.md`：一日游、二日游、西海大峡谷推荐路线。
- `04_transport.md`：南大门、东大门、北大门、黄山北站定制客运和购票渠道。
- `05_ticket_booking_service.md`：票务、预约、服务热线和游客服务边界。
- `06_safety_visit_tips.md`：山地安全、天气、装备、老人儿童建议和兜底话术。
